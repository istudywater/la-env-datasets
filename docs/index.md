# Louisiana Environmental GIS Data Hub

<span class="md-source-date">
**Last Updated:** {{ git_revision_date_localized }}
</span>

Welcome to the Louisiana Environmental GIS Data Hub. This site is a curated collection of public geospatial datasets, GIS workflows, and standard operating procedures (SOPs) commonly used in environmental engineering and consulting projects throughout Louisiana.

The purpose of this website is to provide a centralized reference for:

- Publicly available Louisiana GIS datasets
- Regulatory and environmental data sources
- Instructions for working with common geospatial formats
- Reproducible GIS workflows (IDW, contours, isopleths, CRS handling, etc.)
- Practical QGIS guidance for environmental professionals

---

## Getting Started

If you are new to GIS or do not currently have a GIS platform installed, you are strongly encouraged to download **QGIS**, a free and open-source desktop GIS application:

👉 https://qgis.org

QGIS is used throughout this site for:

- Making figures and maps
- Loading shapefiles, Feature Services, WMS/WFS layers
- Generating contours and isopleths
- Performing interpolation (IDW, TIN, etc.)
- Reprojecting data and managing coordinate reference systems (CRS)

All workflows described here assume use of QGIS unless otherwise noted.

---

## What You’ll Find Here

### Dataset Library
Curated Louisiana datasets organized by category:

- Administrative boundaries (parishes, municipalities)
- Environmental regulatory layers (LDEQ, EPA, solid waste, etc.)
- Hydrology and watersheds
- Topography and elevation data
- Infrastructure and base mapping layers

Each dataset page includes source information, CRS details, format type, and instructions for loading into QGIS.

---

### Working With Data
Guides for handling common geospatial formats:

- Shapefiles (.shp)
- ArcGIS Feature Services (REST)
- Map Services (MapServer)
- WMS / WFS
- CSV files with latitude/longitude
- GeoJSON and GeoPackage
- Raster data (DEM, LiDAR)

These pages focus on practical steps for bringing data into QGIS and preparing it for mapping and analysis.

---

### GIS SOPs
Standard operating procedures developed for environmental projects, including:

- Coordinate Reference Systems (CRS) best practices
- Louisiana State Plane vs UTM usage
- IDW interpolation
- Contour and isopleth generation
- Groundwater surface mapping
- GIS QA/QC procedures

These workflows are structured for repeatability and technical defensibility in reports and regulatory submittals.
